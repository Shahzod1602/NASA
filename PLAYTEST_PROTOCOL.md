# Qisqa playtest protokoli — kelajak bosqich

Haqiqiy datasetli build tayyor bo‘lgach, yangi foydalanuvchilar bilan o‘tkaziladi. **Hozir qatnashchi ham, natija ham yo‘q.** Ism yoki boshqa shaxsiy ma’lumot kerak emas; sessionga anonim raqam yetarli.

Oldindan, keyin esa yana shu uch savol beriladi:

1. Ikki nuqta orasidagi eng qisqa yo‘l doim eng tez yo‘l bo‘ladimi? Sababini ayting.
2. Asosiy vazifa va optional ilmiy vazifa bor, resource cheklangan. Qaror uchun qaysi ma’lumotni ishlatasiz?
3. Xarita balandligi datasetdan olingan, yurish tezligi va resource koeffitsiyentlari sozlangan. Qaysisi o‘lchovga, qaysisi soddalashtirilgan modelga asoslangan?

Jarayon: qisqa tutorial → mustaqil planning → rescue → optional qaror → debriefni o‘qish. Moderator yo‘lni tanlab bermaydi; yordam bergan holatni qayd qiladi. Foydalanuvchidan debriefda o‘z qarorini izohlash so‘raladi.

Har session uchun: build/hash, route, completion/outcome, active vaqt, yordamlar, tushunarsiz joylar, UI o‘qilishi, foydalanuvchining aynan aytgan fikri, oldin/keyin javoblar. Javoblar mezoni: 0 = tushuncha yo‘q; 1 = qisman; 2 = sabab va cheklovni to‘g‘ri ajratadi. Kichik sinovdan ilmiy samaradorlik yoki statistik ahamiyat da’vosi chiqarilmaydi.
