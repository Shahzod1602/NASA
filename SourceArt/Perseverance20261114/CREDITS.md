# Perseverance visual reference for fictional NOMAD-7

Source: **NASA / Jet Propulsion Laboratory**, [Mars 2020 Perseverance Rover](https://science.nasa.gov/3d-resources/mars-2020-perseverance-rover/).

The NASA 3D Resources [repository statement](https://raw.githubusercontent.com/nasa/NASA-3D-Resources/master/README.md) describes these resources as free and without copyright. Follow the [NASA images and media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/), including credit and restrictions on implying endorsement or using protected NASA identifiers. The project does not apply its own code license to NASA material.

`Raw/Mars2020Perseverance.glb` is the unchanged official download. Its SHA-256, download date and source URL are in `manifest.json`.

OpenAI Codex assisted with Draco decoding, baking node transforms, retaining all 199,521 source triangles, combining static mesh containers, preserving PBR material/UV assignments, capping source texture dimensions at 2048 and generating Unreal LODs. No locomotion animation or physical rover simulation was taken from this asset.

In the fictional SELENE rescue scenario this model supplies only the appearance of NOMAD-7. Its memory-recovery target, controls and rewards remain authored game mechanics. **Perseverance is a Mars mission; it did not visit the Moon.** This is not historical Apollo equipment, real lunar research, a NASA partnership or an endorsed simulator.
