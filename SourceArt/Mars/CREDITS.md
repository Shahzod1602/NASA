# Mars expedition assets

Mars terrain geometry, material shaders, map composition and ascent lander are
procedurally authored for this project by Tools/build_mars.py. The terrain is
fictional. Existing shared habitat, rover, terminal and rock assets retain their
original credits under SourceArt; no additional third-party assets were fetched.

English radio speech was synthesized locally with Microsoft Zira Desktop and
processed into a radio effect by Tools/filter_mars_audio.py.
